## Gemini task protocol
- Before editing, inspect the current branch, working tree, open PRs, and recent commits.
- Confirm the exact task, owned files, base branch, and acceptance criteria with the lead coordinator.
- Do not edit files currently owned by another active agent.
- Create/use a dedicated task branch; never push directly to `main`.
- Keep changes limited to the assigned scope.
- For research, provide primary-source links and exact standards editions/clauses; distinguish verified facts from assumptions.
- For calculation changes, provide equations, units, sign conventions, boundary conditions, independent examples, and regression tests.
- Open or update a PR and report changed files, commands run, results, limitations, and handoff status.
